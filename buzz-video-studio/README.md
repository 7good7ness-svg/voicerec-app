# バズ動画スタジオ

YouTubeショートを毎日1本、15分で作り続けるためのワークフローアプリ。
「全部AIに任せると平均1500再生、ネタだけ人間が選ぶと11万再生」という実体験を、
そのまま画面の制約として実装しています。

依存パッケージゼロ。ブラウザだけで動きます。データは端末の localStorage にのみ保存され、
APIキーを含めどこにも送信しません（Gemini を使う時だけ、ブラウザから Google に直接リクエストします）。

## 起動

```bash
node serve.mjs          # → http://localhost:5173
```

`index.html` を直接開いても動きますが、`file://` だと Gemini API 呼び出しが CORS で失敗します。
AI生成を使うならサーバー経由で開いてください。

## 5ステップ

### 1. ネタ（人間の仕事）
題材・出どころ・参照した伸びている動画・飽和度を入力すると **ネタ強度が100点満点で出ます**。

- 「AIにネタごと考えさせた」を選ぶと出どころが25点中4点まで落ちる
- チャンネルのジャンルとネタのジャンルが違うと20点中4点（別ジャンル判定でおすすめが止まる失敗の防止）
- 参照動画の再生数と鮮度、冒頭2秒フックの具体性（数字・意外性・二人称）を採点

75点未満で先に進もうとすると、赤字で理由が出ます。

### 2. 台本（AIの仕事）
構成の型（切り抜き／逆張り／ランキング／実話）を選んで生成します。

- **AIに書かせる**: Gemini API（キーは「API設定」から。記事の筆者の実績では数百円で足ります）
- **プロンプトをコピー**: Claude や ChatGPT に貼って使う。APIキー不要
- **テンプレで下書き**: オフラインでも動く型の雛形

生成後は自動で以下が走ります。

- **尺の推定**: モーラ数から読み上げ秒数を計算（話速は調整可）。フックが2.5秒を超えると警告
- **AIっぽさ診断**: 「いかがでしたでしょうか」「皆さん」「近年」などのテンプレ表現、文長の均一さ、
  敬体の連続を検出して、直し方まで出します。「AIで作った動画ですよね？」と言われる前に潰すため

### 3. テロップ
AIは文字の大きさ・位置・色を知りません。ここで数値として固定して渡します。

- プリセット3種（パンチ／クリーン／ニュース）、フォント・サイズ・縁取り・色・位置・余白を指定
- **1枚あたりの文字数上限**（初期値13文字）を超えるとエラー。ナレーション全文を字幕にする失敗を機械的に止めます
- ショートのUI安全域（下480px・上220px・右200px）に被るとエラー
- 実寸1080×1920のプレビューで再生確認、`telop.ass` / `subtitle.srt` を書き出し

### 4. 編集
- 縦1080×1920への整形＋テロップ焼き込み＋音量正規化＋BGMダッキングまで入った ffmpeg コマンド
- 素材が複数ある場合の `render.sh`（カットごとに切って結合）
- カット表（時刻・映像指示・テロップ・読み）
- 読み上げの作り方（VOICEVOX／肉声録音）。**フックだけ肉声**の混成を推奨表示

### 5. 運用
- 投稿前チェックリスト（実際に踏んだ失敗をそのまま項目化）
- **収益化ペース**: 90日/300万再生に対する現在地、必要な1日あたり再生数（33,333）、
  このペースの着地予測。10万再生1本は3.3%だと常に表示されます
- 投稿ログと、当たり／外れの平均比較。次に複製すべき差分を出します

## テスト

```bash
node --test tests/logic.test.mjs
```

採点・尺推定・ASS生成・ffmpegコマンド・KPIの計算はすべてDOM非依存の純関数で、39件のテストがあります。

## ファイル構成

```
index.html          画面
css/style.css
js/app.js           UI配線（DOM）
js/topic-score.js   ネタ強度の採点
js/script-gen.js    プロンプト生成・Gemini呼び出し・オフライン下書き
js/ai-ness.js       AIっぽさ診断
js/mora.js          モーラ数からの尺推定
js/telop.js         タイムライン・ASS/SRT生成・テロップ検証
js/ffmpeg.js        レンダーコマンド・カット表
js/kpi.js           90日/300万再生のペース計算
js/store.js         localStorage
serve.mjs           依存ゼロの静的サーバー
```

## 素材の扱いについて

切り抜きを使う場合、引用の範囲・利用許諾・各プラットフォームの規約は自分で確認してください。
チェックリストに項目はありますが、アプリ側で権利を判定することはできません。
